My Projects

Here are some of the projects I have worked on during my studies and personal development.

First project · Team Project

Weather App

This was one of my first web development projects. We were a team of four students, and at that time we were learning HTML, CSS and basic JavaScript. The app shows weather in Sweden and Rwanda, and users can also search for weather in other cities.

My Contribution

I mainly worked on the frontend. I worked with HTML and CSS and was also responsible for making the website responsive.

Challenge & Solution

The hardest part for me was responsive design because I did not know much about it at the time. A classmate suggested Bootstrap, but I had never used it before. I spent about two days learning the basics and then used Bootstrap to make the website work better on different screen sizes.

Course Project

Recipe Planner

Recipe Planner is a full-stack project I built about a year ago. The application is used to manage recipes. Users can add, edit and delete recipes, search for recipes, save favorites and create a shopping list.

What I Worked With

I built the frontend with React, TypeScript and Bootstrap, and used .NET and SQLite for the backend. This was one of my first larger projects where I worked with both frontend and backend in the same application.

Challenge

I was still quite new to full-stack development when I built this project. It was also my first time using TypeScript, so I was not used to the syntax and often found it confusing at the beginning. Another challenge was getting the React frontend, .NET backend and database to work together, especially when recipe data was added, edited or deleted. I spent quite a lot of time testing and fixing different parts before everything worked together.

Graduation Project

Deepwell Education System

This was my graduation project for the .NET System Development programme. I built a web application for a language school where visitors can browse courses, students can apply for courses and send messages, and administrators can manage courses, applications and communication.

What I Worked With

I worked on both the frontend and backend of the system. I built the backend with ASP.NET Core and Entity Framework Core, and used HTML, CSS and JavaScript for the frontend. I also added an AI feature that can help administrators understand messages, create short summaries and suggest replies.

Challenge

One problem I found was that some of the language lists were written directly in the frontend. When an administrator added a new language course, the new language appeared on the course page, but not on the home page or in the navigation menu. I changed this so the language lists use data from the backend instead. After that, a new language could appear automatically in different parts of the website.
