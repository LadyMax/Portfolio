# Lab 2 – Interactive Personal Portfolio

Student: Brenda Dong  
Target grade: Grade 5

## About

This is an updated version of my portfolio from Lab 1.  
In Lab 2, I added JavaScript features to the feedback form and skills section.

Start page: `html/index.html`

## Features

### Feedback Form
- Form validation with JavaScript
- Validation for name, email, topic, comments and website
- Error messages for invalid input
- Character counter for comments
- Success message after submission

### Skills
- 8 skills in 4 categories
- Skill cards created with JavaScript
- Filter skills by category
- Sort skills by proficiency, experience or name
- Show the number of displayed skills
- Keyboard-accessible filter buttons
